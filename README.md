## 🚀 About Me

I'm a **backend developer from Iran**, working primarily with **PHP and Laravel**.
Over the past **3+ years**, I've worked on freelance projects involving ordering,
payments, organizational workflows, and third-party integrations.

I enjoy figuring out how the pieces fit together: database design, API contracts,
background jobs, permissions, and the details that keep an application reliable.

- 🛠️ Building and maintaining Laravel applications and REST APIs.
- 🐳 Working with Docker, Laravel Sail, PostgreSQL, MySQL, and Redis.
- 🧪 Writing automated tests and investigating bugs beyond the happy path.
- 🤝 Collaborating through Git, code reviews, and clear API documentation.
- 🌱 Always learning through real projects and the problems they bring.
